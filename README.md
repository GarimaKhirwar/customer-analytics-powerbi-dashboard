
# 📊 Customer Analytics Dashboard (Power BI)

## 📌 Project Overview

This project presents an interactive **Customer Analytics Dashboard** built using Power BI.
The dashboard analyzes customer engagement, conversion behavior, and product performance to generate business insights.

⚠️ **Note:** The original dataset was provided in the tutorial as a SQL Server backup (`.bak`).
A cleaned CSV version will be added to improve reproducibility.

---

## 🎯 Objectives

* Analyze customer conversion funnel
* Track social media engagement
* Evaluate product-wise performance
* Monitor customer ratings and sentiment
* Build an interactive BI dashboard

---

## 📊 Key Insights

* Overall Conversion Rate: **9.57%**
* Total Views: **9M**
* Total Clicks: **2M**
* Total Likes: **414K**
* Average Customer Rating: **3.69**
* Major drop observed between **Click → Purchase** stage
